# Agent Note：鑫哥专属桌面版模型目录

Status: implemented

[English](2026-09-16-xinge-desktop-model-catalog.md) | 中文

## 问题

个性化桌面安装包虽然安装了多提供方适配器，却没有为它声明任何路由。即使用户保存了私有中转站密钥，在手动重建端点、协议和模型列表之前，界面仍只会显示内置 DeepSeek 目录。因此，重装应用只能保留个性化外壳，预期使用的 Gemini 与 GPT 模型不会随安装包出现。

## 决策

桌面宿主补丁现在声明 `tokaxis` OpenAI 兼容路由、它的 Gemini 与 GPT 对话模型目录，并把 `gemini-3.8-flash-high` 设为新会话默认模型。该路由只把 `XINGE_DS_API_KEY` 声明为凭据引用，应用安装包不包含任何凭据值。用户设置仍可覆盖路由，而可写凭据存储仍是本地桌面版保存所有者密钥的唯一位置。

生图专用模型 id 不进入对话模型选择器。当前 Harness 适配器会通过聊天补全接口调用所选模型，而这些模型必须使用图像生成端点。把它们显示在该选择器中，只会产生一个无法完成 agent 轮次的可见选项。

## 考虑过的替代方案

**只把路由写进所有者的用户设置。** 拒绝，因为这只能修复一台机器，每次全新安装仍会得到空白的个性化模型目录。用户设置应当作为覆盖层，而不是产品预期提供方的唯一定义。

**把专用 API 密钥打进应用。** 拒绝，因为应用压缩包与仓库发布版都是可分发产物。私有凭据只能保存在所有者本机凭据存储中，禁止进入源码历史或发布资产。

**把生图模型 id 与对话模型放在一起。** 拒绝，因为该选择器会发起 agent 聊天补全请求。必须使用图像生成端点的模型即使显示出来，也无法使用。

## 后果

全新安装的个性化桌面版无需手动录入目录，即可显示预期的 Gemini 与 GPT 对话模型。所有者保存私有中转站凭据后，新会话会默认使用 Gemini 3.8，也可切换到目录中的其他模型。安装包与仓库历史不会包含密钥。专用生图能力仍作为独立能力处理，不会伪装成无法使用的对话模型选项。
