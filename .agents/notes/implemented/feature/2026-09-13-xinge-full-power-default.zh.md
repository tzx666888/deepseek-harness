# Agent Note：将鑫哥全能模式设为个性化桌面版默认模式

Status: implemented

[English](2026-09-13-xinge-full-power-default.md) | 中文

## 问题

个性化桌面版 fork 在新建会话时仍会进入上游随附的标准模式。标准模式已能完成普通编码工作，但没有启用持久终端、结构化替换编辑器、Codex 产品提供方和运行时组装工具，与所有者对 Codex 式全能助手的预期不符。这些能力已经存在于仓库中，却分散在可选产品组合包、默认禁用的 preset 行与创造模式中，因此仅修改应用品牌并不会改变新会话的实际能力。

## 决策

Web 组合包现在通过一条由组合包持有的宿主行安装 Codex 子任务提供方，并把 `cordis` preset 选为部署默认值。该 preset 对用户显示为 **Xinge Full Power** / **鑫哥全能模式**，保留标准模式的文件、Shell、联网、图像读取、Skills、计划、目标、后台任务、委派、工作流和交付工具。在此基础上，它还挂载按 agent 隔离的持久终端栈，暴露结构化替换编辑器，启用 Codex 委派工具，并保留原有 Cordis 运行时检查与扩展工具。

在 macOS 上，桌面壳会发现本机已安装的 Peekaboo 可执行文件，也可通过 `DSH_CONTROL_COMMAND` 接收其绝对路径。鑫哥全能模式会在 agent preset 内按条件启动该 MCP 服务器，并以 `mcp__desktop__` 命名空间提供屏幕观察、应用、窗口、指针和键盘工具。其他 preset 以及未安装该可执行文件的环境不会获得这些工具；具体操作仍由 macOS 的“屏幕录制”和“辅助功能”授权决定。

既有工具的安全边界保持不变。一次性与持久命令仍经由宿主沙箱和审批策略处理，终端会话仍按所属 agent 隔离，Codex 提供方继续使用非交互权限策略。现有用户 preset 选择仍具有最终决定权：只有在用户没有覆盖选择其他 preset 时才使用新的部署默认值，标准、PTC、极简与自定义 preset 仍可选。

## 考虑过的替代方案

**把所有能力复制进标准模式。** 拒绝，因为标准模式是测试、文档与用户自建副本使用的稳定通用基线。扩展现有 Cordis 超集可为本 fork 提供更强的默认能力，同时不在所有地方暗中改变标准模式。

**把 Schedule 作为全能 preset 的一部分全局启用。** 拒绝，因为当前 Schedule 持有方会从宿主层向每个根 agent 附加工具。在 Web 组合包中启用它也会扩展极简模式，破坏该模式刻意保留的单工具约定。后续可以在具备 preset 感知能力的持有接缝后添加定时任务。

**从宿主工具注册表暴露桌面控制。** 拒绝，因为每个 preset 都会继承这些工具，包括极简模式。按条件启用的 MCP 行属于鑫哥全能模式，因此仍由所选 preset 决定 agent 能力。

**把自动化可执行文件打进应用。** 拒绝，因为该可执行文件有独立的发布、签名和操作系统权限生命周期。发现本机已安装的可执行文件，使更新与 macOS 授权仍由该组件负责。

## 后果

没有已保存覆盖值的新桌面版与浏览器会话会默认进入鑫哥全能模式，可立即使用持久交互程序、结构化文件替换、原生委派、Codex 委派、工作流与运行时扩展。在装有 Peekaboo 且具备所需系统授权的 macOS 上，这些会话也能观察和操作可见的桌面应用。可选 Codex 运行时与 MCP client 成为安装闭包的一部分，会增加打包体积。依赖外部账户的能力仍仅在配置对应提供方或 MCP 连接后出现。既有会话保留创建时的 preset，因此用户需要新建会话才能获得新的默认能力。
